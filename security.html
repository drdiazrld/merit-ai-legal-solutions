What stays on the assigned environment

Original client documents

Original client documents are stored on infrastructure dedicated to the firm. Merit does not upload the original file to a model provider.

Local document processing

Text extraction and OCR run locally on the assigned machine. Optional embeddings also run locally. Embeddings are not persisted, and the feature is off by default.

What may be sent for model processing

A configured cloud model may receive text selected for the task. Today, that text may also include document titles and document-type labels.

The provider receives text, not the original file. A title can contain identifying information, so firms should treat titles as part of the information that may leave the assigned environment.

Restricted runtime controls

The configured Lodestar environment narrows what the approved cloud-model lane can do. Model calls run in a read-only execution sandbox with web search turned off. Only a limited set of environment fields is inherited, prompts are text-only, and local matter memory is blocked from remote calls.

These configured controls reduce exposure, but they do not establish provider no-training or zero retention, at-rest encryption, logged support access, deletion that includes backups, or absolute isolation.

Access and matter scope

Access to the desk

Access uses the firm’s Microsoft Entra tenant sign-in and a seat second factor. Connections use TLS through a single Cloudflare hostname.

Matter storage

Matter data is stored in per-seat, per-matter scopes. This describes the current storage structure and is not an absolute isolation guarantee.

Attorney-controlled actions

Consequential external actions remain manual and require attorney review.

Merit returns work for review. The attorney decides whether to send, file, serve, or submit it and completes that action outside the preparation step.
